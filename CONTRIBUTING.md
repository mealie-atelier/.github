# Contributing

Thank you for helping with Mealie Atelier. The product lives in two repositories, and each one has its own contributing guide with the exact commands for formatting, tests and builds:

- [`mealie-atelier-cards`](https://github.com/mealie-atelier/mealie-atelier-cards/blob/main/CONTRIBUTING.md): Home Assistant dashboard cards, the standalone web app and the demo.
- [`mealie-atelier-bridge`](https://github.com/mealie-atelier/mealie-atelier-bridge/blob/main/CONTRIBUTING.md): the Home Assistant integration.

## Before you open a pull request

- Open an issue first for larger changes, so the direction is agreed before you invest time.
- Keep a change focused on one topic and add tests. A bug fix needs a test that fails without the fix.
- Write source, comments, commit messages and documentation in English. Text that users see is available in German and English.
- Never include tokens, passwords, personal data or private hostnames.
- Report security problems privately as described in [`SECURITY.md`](SECURITY.md), not in a public issue.

## Conduct

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md). Questions about usage go to [`SUPPORT.md`](SUPPORT.md).

Changes to the shared community files, the brand assets or the organization profile are made here. The [README](README.md) lists what each file does.
