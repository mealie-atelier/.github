# Mealie Atelier organization files

Public profile, shared community files and brand masters of the [Mealie Atelier organization](https://github.com/mealie-atelier). The product source lives in its own repositories.

| Repository | Content |
| --- | --- |
| [`mealie-atelier-cards`](https://github.com/mealie-atelier/mealie-atelier-cards) | Home Assistant dashboard cards, the standalone web app (`web/`) and the bilingual demo (`demo/`) |
| [`mealie-atelier-bridge`](https://github.com/mealie-atelier/mealie-atelier-bridge) | The Home Assistant integration `mealie_atelier` and the live acceptance rig (`tests/live/`) |
| `.github` (this repository) | [Organization profile](profile/README.md), [support](SUPPORT.md), [security policy](SECURITY.md), [code of conduct](CODE_OF_CONDUCT.md), [issue templates](ISSUE_TEMPLATE/bug_report.md), [pull request template](pull_request_template.md), [funding](FUNDING.yml) and [brand assets](brand/README.md) |

Cards and Bridge are released independently. Each repository has its own changelog.

## Where things are

- [`profile/README.md`](profile/README.md): the profile shown on the organization page.
- [`SUPPORT.md`](SUPPORT.md), [`SECURITY.md`](SECURITY.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/bug_report.md), [`pull_request_template.md`](pull_request_template.md), [`FUNDING.yml`](FUNDING.yml): defaults inherited by repositories that do not define their own.
- [`brand/`](brand/README.md): icons, social previews and credits.

## Brand asset use

The `brand/` directory holds the Week Dial marks, lockups, icons and repository social previews. Font credits and rebuild steps are in [`brand/CREDITS.md`](brand/CREDITS.md) and [`brand/README.md`](brand/README.md). These notes do not grant a license to reuse the project identity or artwork.
