# Mealie Atelier organization files

This repository contains the public profile and shared community files for the [Mealie Atelier organization](https://github.com/mealie-atelier). It is not the application source repository.

## Project repositories

| Project | Purpose | Status |
| --- | --- | --- |
| [Atelier Cards](https://github.com/mealie-atelier/mealie-atelier-cards) | Recipe experience and optional Home Assistant cards | In development; no code or release published yet |
| [Atelier Bridge](https://github.com/mealie-atelier/mealie-atelier-bridge) | Optional Home Assistant integration and kitchen workflows | In development; no code or release published yet |

Both project repositories currently contain status information only. Do not treat screenshots, local previews, or planning archives as installable releases. Compatibility, setup steps, and supported features will be documented against published source and tested releases.
