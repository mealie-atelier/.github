# Mealie Atelier organization files

Public profile, shared community files and brand masters of the [Mealie Atelier organization](https://github.com/mealie-atelier). The product source lives in its own repositories.

| Repository | Content |
| --- | --- |
| [`mealie-atelier-cards`](https://github.com/mealie-atelier/mealie-atelier-cards) | Home Assistant dashboard cards, the standalone web app (`web/`) and the bilingual demo (`demo/`) |
| [`mealie-atelier-bridge`](https://github.com/mealie-atelier/mealie-atelier-bridge) | The Home Assistant integration `mealie_atelier` and the live acceptance rig (`tests/live/`) |
| `.github` (this repository) | [Organization profile](profile/README.md), [support](SUPPORT.md), [security policy](SECURITY.md), [funding](FUNDING.yml) and [brand assets](brand/README.md) |

Cards and Bridge are released independently. Each repository has its own changelog.

## Brand asset use

The `brand/` directory holds the organization icon, the product icons and the repository social previews. Photography credits and export steps are in [`brand/CREDITS.md`](brand/CREDITS.md) and [`brand/README.md`](brand/README.md). These notes do not grant a license to reuse the project identity or artwork.
