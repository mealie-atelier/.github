# Support

Mealie Atelier is in development. Public source code is available, but there are no stable catalog packages or production releases yet. Follow the repository-specific guides for developer-preview installation and the open acceptance gates before relying on it as a stable setup.

- For general questions and ideas, use [organization Discussions](https://github.com/orgs/mealie-atelier/discussions).
- For current release blockers, previews, and next work items, see the [canonical open-work index](https://github.com/mealie-atelier/mealie-atelier-cards/blob/main/docs/OPEN_TODOS.md).
- Before asking a setup question, see the [Cards FAQ](https://github.com/mealie-atelier/mealie-atelier-cards/blob/main/docs/FAQ.md) or [Bridge FAQ](https://github.com/mealie-atelier/mealie-atelier-bridge/blob/main/docs/FAQ.md).
- For a reproducible bug in the available source, open an issue in [Atelier Cards](https://github.com/mealie-atelier/mealie-atelier-cards/issues) or [Atelier Bridge](https://github.com/mealie-atelier/mealie-atelier-bridge/issues).
- For a security vulnerability, use the private reporting links in [`SECURITY.md`](SECURITY.md), not a public issue.
- For project news and future documentation, visit [alles-automatisch.de](https://alles-automatisch.de/).
- If the project is useful to you, [support it on Ko-fi](https://ko-fi.com/allesautomatisch). This is completely optional and does not unlock features.

When reporting a problem, include the project version, Home Assistant and Mealie versions if relevant, the expected result, and a short reproduction. Redact hostnames, access tokens, private recipe details, and personal data from logs and screenshots.
