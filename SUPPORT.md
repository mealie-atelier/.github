# Support

Mealie Atelier is in development. The project repositories do not yet contain installable code or released packages.

- For general questions and ideas, use [organization Discussions](https://github.com/orgs/mealie-atelier/discussions).
- For a reproducible issue in a published project, open an issue in [Atelier Cards](https://github.com/mealie-atelier/mealie-atelier-cards/issues) or [Atelier Bridge](https://github.com/mealie-atelier/mealie-atelier-bridge/issues).
- For a security vulnerability, use the private reporting links in [`SECURITY.md`](SECURITY.md), not a public issue.
- For project news and future documentation, visit [alles-automatisch.de](https://alles-automatisch.de/).

When reporting a problem, include the project version, Home Assistant and Mealie versions if relevant, the expected result, and a short reproduction. Redact hostnames, access tokens, private recipe details, and personal data from logs and screenshots.
